Proposed File Editor model — 3 states

For Markdown: default is the rendered Formatted view, with a toggle to Source (raw + line numbers + colour). Edit opens the code editor. For JSON/YAML/txt there's no prose form, so the Formatted/Source toggle is hidden — they always show the coloured code view, and Edit works the same.
