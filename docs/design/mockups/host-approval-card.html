Host approval card

When a run drafts or edits a tool that wants to reach an external host, the run ends and this card appears in the chat — the just-in-time place to approve. Approving is the owner's decision; the agent can never grant a host to itself. The card reuses the dashboard's own card, button, and status vocabulary; its one distinguishing mark is a thin --amber left rule that reads as "needs your call" without breaking the calm of the stream.
