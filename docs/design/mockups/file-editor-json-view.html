How should JSON (and other non-Markdown files) display in read mode?

Today every file is run through the Markdown renderer, so JSON collapses into one unformatted blob. Both options below add line numbers + proper indentation. The difference is colour.

A — Pretty-print + line numbers (no colour)

Indented, one item per line, gutter with line numbers. Monospace, single text colour.

Zero new dependencies. ~30 lines of code. Fits the minimalist codebase (react + marked + dompurify only).

B — Pretty-print + line numbers + syntax colour

Same layout, plus coloured keys / strings / numbers / booleans — reads like a real code sample.

Small custom tokenizer (JSON only), or a tiny highlight lib. ~80–120 lines, or one dependency. More polish, slightly more code to maintain.

There's also a heavier option C — render JSON as a collapsible key/value tree — but that drifts away from a "code editor" feel and is more code. I'd skip it unless you want it.
